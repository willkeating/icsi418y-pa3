# ICSI 418Y PA3

This project extends PA2 with projects and project memberships ontop of the existing signup and login component
a user can create a project, select a leader, view projects, and add or remove members.

# how to run

Open the project in IntelliJ
Run server.js to start the backend
Go to the client folder and run npm run dev in terminal
Open url provided by previous command

Uses React, Express, and MongoDB.
